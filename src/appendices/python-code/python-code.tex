\section{Código en Python}
    \label{anexo_python}
    El script \textit{statistics.py} regenera el dataset con semilla fija, construye la
    tabla de frecuencias por la regla de Sturges, calcula las medidas de tendencia

    las cinco figuras del informe. Se reproduce completo y en su orden de ejecución, con
    sus bloques correspondiéndose uno a uno con las subsecciones de la metodología.
