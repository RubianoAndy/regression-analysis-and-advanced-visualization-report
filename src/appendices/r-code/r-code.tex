\section{Código en R}
    \label{anexo_r}
    La fase 5 de la Tabla \ref{workflow} se implementa en R. El guion no reutiliza
    ningún valor calculado en Python, únicamente lee el mismo archivo de datos, de
    modo que la comparación entre ambas implementaciones es directa.

    \vspace{10pt}

    \textit{regression.R} reestima con \texttt{lm()} los dos modelos que la fase 2
    ajustó con \textit{statsmodels}, los contrasta con \texttt{anova()}, compara
    coeficiente a coeficiente contra la tabla que escribió Python para producir la
    Tabla \ref{cross_check}, y construye con \textit{ggplot2} las Figuras
    \ref{ggplot_fit}, \ref{ggplot_facets} y \ref{ggplot_pred}.
